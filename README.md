## Install

- If the zip nested a folder inside a folder, go into the inner one.
- Continue until the folder you are in shows `setup`.
- Launch `setup` in the folder where you found it.

## What's inside

## Short FAQ

<details><summary>Does it need internet to run?</summary>

No. The build runs offline. A download is only needed when a newer archive is published.
</details>

<details><summary>I have a diff sitting here. Will it be accepted as a change to the files?</summary>

File the request as an issue. A code submission is not taken, because what is published here is a finished build.
</details>

<details><summary>How do I get a newer build?</summary>

Download the later archive. Copy aside anything you added before extracting over the old folder.
</details>

<details><summary>How do I pick up a newer build without losing files I added?</summary>

Download the later archive. Copy aside anything you added before extracting it over the old folder.
</details>

<details><summary>Can two people on the same PC use it?</summary>

Yes. Each user extracts a copy under their own account. The folders do not share state.
</details>

<details><summary>Windows says the downloaded file is blocked. What do I tick?</summary>

The block comes off when you open Properties and tick Unblock. Start `setup` after that.
</details>
